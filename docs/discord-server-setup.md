# Discord Server 設定步驟（Windows）

這份文件帶你完成三件事：
1. 建立你自己的 Discord Server
2. 建立給 agent 用的頻道，並拿到它的 `CHANNEL_ID`
3. 產生邀請連結，讓同組同學加入

> **關於介面文字**：下面的按鈕名稱以英文介面為主，括號裡是中文介面大概的寫法。Discord 改版時文字可能有一點不同，找意思最接近的按鈕就好。
>
> 用 Discord 桌面版（Windows 應用程式）或瀏覽器打開 <https://discord.com/app> 都可以，步驟一樣。

---

## 一、建立你自己的 Discord Server

1. 打開 Discord 並登入。
2. 看畫面**最左邊那一排圓形圖示**，往下捲到底，點綠色的 **「+」**（Add a Server／新增伺服器）。
3. 跳出的視窗裡，點最上面的 **「Create My Own」**（建立我的伺服器）。
4. 問你「這個伺服器是給誰用的」時，點 **「For me and my friends」**（我和我的朋友）。
5. **Server Name**（伺服器名稱）欄位輸入名字，例如 `食物記錄測試`。圖示可以不放。
6. 點右下角的 **「Create」**（建立）。
7. 左邊那一排會多出你的新伺服器圖示，Discord 也會自動切換進去。

---

## 二、建立 agent 專用的頻道

1. 在你的伺服器裡，看**左邊頻道清單**，找到 **「TEXT CHANNELS」**（文字頻道）這個標題。
2. 滑鼠移到標題上，右邊會出現一個小 **「+」**，點它（Create Channel／建立頻道）。
3. **Channel Type**（頻道類型）選 **「Text」**（文字）。
4. **Channel Name**（頻道名稱）輸入例如 `food-log`。
5. 「Private Channel」（私人頻道）**不要打開**，同學才看得到。
6. 點右下角的 **「Create Channel」**（建立頻道）。
7. 左邊頻道清單會出現 `# food-log`。

---

## 三、拿到這個頻道的 CHANNEL_ID

頻道 ID 是一串 18–19 位的數字。要先打開「開發者模式」，Discord 才會顯示複製 ID 的選項。

### 1. 打開開發者模式（只要做一次）

1. 看畫面**左下角**你的頭像和名字旁邊，點 **齒輪圖示**（User Settings／使用者設定）。
2. 設定畫面左邊的清單往下捲，在 **「APP SETTINGS」**（應用程式設定）底下點 **「Advanced」**（進階）。
3. 右邊找到 **「Developer Mode」**（開發者模式），把開關**往右打開**（變成綠色／藍色）。
4. 按鍵盤 **Esc**，或點右上角的 **✕**，離開設定。

### 2. 複製頻道 ID

1. 回到左邊頻道清單，在 **`# food-log` 上按滑鼠右鍵**。
2. 選單**最下面**點 **「Copy Channel ID」**（複製頻道 ID）。
3. 打開記事本，按 **Ctrl + V** 貼上，你會看到一串數字，例如 `1298765432109876543`。這就是 `CHANNEL_ID`。

### 3. 寫進 `.env`

在專案資料夾的 `.env` 檔裡寫一行（數字換成你的，不要加引號、不要有空格）：

```
CHANNEL_ID=1298765432109876543
```

> `CHANNEL_ID` 不算機密，但 `.env` 裡還會放 bot token，所以 `.env` 這個檔案整個都不能 commit（`.gitignore` 已經設定好了）。

---

## 四、產生邀請連結給同組同學

1. 在**左邊頻道清單最上面**，點你的**伺服器名稱**（旁邊有一個向下的小箭頭）。
2. 選單裡點 **「Invite People」**（邀請其他人）。
3. 跳出的視窗最下面有一條連結，先**不要**直接複製，點連結下方的 **「Edit invite link」**（編輯邀請連結）。
4. 設定：
   - **Expire After**（有效期限）：選 **「7 days」**（7 天）。測試完連結就會自己失效。
   - **Max Number of Uses**（使用次數上限）：選比組員人數多一點的數字，例如 **「10 uses」**。
5. 點 **「Generate a New Link」**（產生新連結）。
6. 回到上一個畫面，點連結右邊的 **「Copy」**（複製）。
7. 把連結傳給同組同學（LINE、Email 都可以）。他們點開、登入 Discord、按 **「Accept Invite」**（接受邀請），就會加入你的伺服器，也看得到 `# food-log`。

> 邀請連結只要不公開貼在網路上就沒關係。要是不小心外流了，可以到 **伺服器名稱 → Server Settings（伺服器設定）→ Invites（邀請）**，把那條連結刪掉。

- [ ] 左邊有你的伺服器圖示
- [ ] 伺服器裡有 `# food-log` 文字頻道
- [ ] `.env` 裡有 `CHANNEL_ID=一串數字`
- [ ] 同組同學已經加入伺服器
